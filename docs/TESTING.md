# Practical in-game checklist

Target: official Classic Hardcore **1.15.9 / 70003 / 11509**, **Auctionator 341**. Use a test character and enable Lua errors with `/console scriptErrors 1`, then `/reload`. Restore your preferred error setting afterward. No purchases or gathering risks are necessary to validate the price list.

- [ ] **Install and login:** HerbValue appears in AddOns, opens without Lua errors, shows 31 herbs with no filter, and fits on screen at your UI scale. Scroll through all rows. Inspect icons, names, skill and price columns; verify tooltips and secondary-drop notes.
- [ ] **Toggle/move:** `/hv` and `/herbvalue`, Escape, and the close button work. Drag the title, `/reload`, and log out/in: position and visibility persist. `/hv reset` restores the center. Check after a resolution/UI-scale change.
- [ ] **Known data / unit basis:** scan with Auctionator. For a herb present in a multi-item stack, compare the displayed unit price with Auctionator's API/tooltip, not the total stack buyout. Confirm `g`, `s`, and `c` denominations. Developer comparison: `/dump Auctionator.API.v1.GetAuctionPriceByItemID("HerbValue", 765)` returns raw unit copper for Silverleaf.
- [ ] **Automatic refresh:** leave HerbValue open while an Auctionator search finishes and while a full scan completes. After a meaningful price change, verify automatic updates and price sorting. Repeat with HerbValue closed, then open it. No auction interaction or recurring scan should be started by HerbValue.
- [ ] **Manual refresh:** press Refresh away from the auction house. Cached values should remain available, without a scan or network request. Scan/search at an auction house to change the cache, then check again.
- [ ] **Missing price data:** on a test account/realm with a fresh Auctionator cache, or for an herb not in the scanned data, verify **No price data**, age `--`, and placement after priced herbs in price order. Do not delete the main account's cache for this test. The pure Lua suite covers a real zero independently of `nil`.
- [ ] **Price age:** compare `/dump Auctionator.API.v1.GetAuctionAgeByItemID("HerbValue", 765)` with the row. Zero means Today, positive values are days, and missing age with an available price means Unknown. Confirm cached-price guidance remains visible. Exact minutes/hours are intentionally not shown.
- [ ] **Missing Auctionator:** disable Auctionator on character selection and log in. HerbValue must still open, retain controls, list herbs, and explain missing/disabled Auctionator without errors. Reenable Auctionator and `/reload` to restore prices.
- [ ] **Incompatible API (test session only):** save and temporarily replace the price function: `/run HVTestPrice=Auctionator.API.v1.GetAuctionPriceByItemID; Auctionator.API.v1.GetAuctionPriceByItemID=nil`. Press Refresh; expect an incompatibility message and no stale prices. Restore with `/run Auctionator.API.v1.GetAuctionPriceByItemID=HVTestPrice; HVTestPrice=nil` and Refresh, or `/reload`. This changes memory only; do not edit Auctionator files.
- [ ] **Ordering:** price descending (unknown last), name ascending, and skill ascending all work. Equal-price entries are stable. Filtering/searching keeps the selected order.
- [ ] **Search:** try `lotus`, mixed case, apostrophes, spaces around a name, and `[` (treated literally). Clear it. Test a localized client if available; localized and English names should find the same herb. Non-ASCII case folding follows the client Lua implementation and may vary by locale.
- [ ] **Skill boundaries:** without Herbalism, skill-filtered list is empty. At ranks 1, 15, 50, 75 and 300, inspect boundary herbs. Skill gains, bonuses from equipment/racial effects, and profession unlearning should update without reopening. Collapse the Professions header in the character skill panel; the filter should still work and preserve header state. Test with another skill header collapsed too.
- [ ] **Secondary drops:** Swiftthistle is marked as Mageroyal/Briarthorn loot; Wildvine as Purple Lotus loot; Bloodvine notes Zul'Gurub and Blood Scythe. The displayed skill is the minimum source-node threshold, not a guarantee of a drop, tool possession, or raid access. Verify live server requirements when safely available.
- [ ] **Saved preferences / isolation:** set search, sort and filter, `/reload`, then log out/in. They persist for this character. Another character gets its own settings and uses its own effective skill.
- [ ] **Item cache:** on a fresh client cache, English fallback names/question-mark icons must not break sorting or the list, and cached names/icons should arrive without manual reopening. No unbounded retry loop should occur.
- [ ] **General UI:** test scrolling after a filter reduces the row count, empty results, combat, normal zoning, reopening, and repeated Refresh. Look for clipped content, tooltips lingering after closing, duplicate callbacks, or Lua errors.

## What was tested outside WoW

19 automated Lua 5.1 checks passed, including a mocked frame/event lifecycle and real Auctionator 341 wrapper/database/callback code supplied by the user. The first 18 tests run without an Auctionator source directory. A source-data audit checked all 31 item ID/name pairs, the 30 directly tabulated thresholds, and Bloodvine's source nodes/scythe condition. Packaging checks validate TOC-listed files and ZIP structure.

The mock does not render frames, emulate all Blizzard event timing, or save real WoW SavedVariables. The checkboxes above remain **unrun in-game**, not implied passes. Live auction data, server gathering behavior, and the exact client build have not been exercised by the development machine.
